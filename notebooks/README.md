#### Notebooks Overview

This folder contains a set of Jupyter notebooks for data preparation and analysis.

##### Usage

1. Open the `data_preparation.ipynb` notebook to clean & prepare the data.
2. Proceed to the `eda.ipynb` notebook to perform data analysis.
3. Under the stocks folder, go to each stocks' notebook like `AAPL.ipynb` to visualize its technical indicators and calculate its correlation matrix.
4. The `financial_analysis.ipynb` displays portfolio optimization metrics for the list of stocks using PyNance.
