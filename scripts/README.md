#### Scripts Overview

This folder contains Python scripts used for data preparation, eda, sentiment analysis, plotting etc.

##### Scripts

- `utils.py`: Contains script used in the data preprocessing.
- `eda.py`: Contains script used in the data analysis process.
- `plot.py`: Contains script used for plotting.
- `text_analyzer.py`: Contains script used in headline sentiment analysis.
- `publisher_analyzer.py` : Contains script used for publisher analysis.
- `stock_indicators.py` : Contains scripts for calulating stock technical indicators.
- `financial_metric.py` : Contains scripts for calculating portfolio optimization metrics using PyNance.
